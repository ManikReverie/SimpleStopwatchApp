# Simple Stopwatch App
## Project Overview
A simple Android app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 31). It is a stopwatch application with Start, Pause, and Reset functionalities.
## Technologies Used
- Kotlin
- XML Layouts
- Android Studio
## Features
- Displays elapsed time using Chronometer
- Start, Pause, and Reset buttons
- Accurate time tracking
## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.
## Outcome
The application successfully starts, pauses, and resets the stopwatch based on user interactions.
